# Jeddah Tower · lições para o Senna Tower

Apresentação em HTML (74 slides). Abra `index.html` em um servidor web — localmente ela precisa de um servidor simples (ex.: `npx serve`), pois carrega os slides e vídeos por rede.

## Publicar no GitHub Pages

1. Em github.com → **New repository** (ex.: `jeddah-tower`). No plano gratuito, o Pages só funciona em repositório **público**: qualquer pessoa com o link verá a apresentação.
2. No repositório vazio, clique em **uploading an existing file** e arraste **todo o conteúdo desta pasta** (arquivos e as pastas `assets` e `ds`). Confirme com **Commit changes**.
3. **Settings → Pages → Build and deployment**: Source = *Deploy from a branch*; Branch = `main`, pasta `/ (root)` → **Save**.
4. Em cerca de um minuto a apresentação estará em `https://SEU-USUARIO.github.io/jeddah-tower/`.

Setas do teclado avançam os slides; a tecla de impressão do navegador gera um PDF com um slide por página.
